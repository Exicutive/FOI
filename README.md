# FOI Developments

Static multi-page website using HTML, CSS, and TypeScript. TypeScript compiles to browser-ready JavaScript in `assets/js/`.

## Project structure

```text
assets/
  css/styles.css
  js/main.js              # generated by the build
scripts/generate-sitemap.js
scripts/prepare-static-site.js
dist/                     # generated static site output
pages/
  about.html
  contact.html
  development.html
  properties.html
src/ts/main.ts            # TypeScript source
index.html
package.json
tsconfig.json
```

## Build

Run `npm install` once, then `npm run build` whenever the TypeScript source changes. Serve the project root with a static web server to preview the pages.

## Deploy to Render

The included `render.yaml` configures a Render Static Site. Push it to GitHub, then in Render choose **New + → Blueprint** and connect the `Exicutive/FOI` repository on `main`. Render will run `npm ci --include=dev && npm run build:site` and publish `dist/`.

## Sitemap

After deployment, generate `sitemap.xml` with the production origin. In PowerShell, run `$env:SITE_URL="https://your-domain.example"; npm run sitemap`. The generator also adds the sitemap URL to `robots.txt` and discovers property and development detail URLs from their listing cards.
